Care Manager Sync

Upload Excel with Email Address, Queue Name, and Phone Number. Each row verifies queue membership (joined), station/WebRTC phone, and the Care Managers Lookup data table DNIS row.

Roster sync

Preview shows planned changes. Apply runs live updates using server credentials (queue membership, optional WebRTC phone at Headquarters, new data table rows).

Download Excel template Email Address, Queue Name, Phone Number — delete the example row before Apply.

Data table row fields (new rows)
  • DNIS — phone from spreadsheet (E.164)
  • QueueName — queue from spreadsheet
  • Skill — NCM
  • CenterQueue — matching Patient Services queue (from NCM queue suffix)
  • Open — true

Override table name with CALL_MANAGERS_DATATABLE_NAME or CARE_MANAGERS_LOOKUP_DATATABLE_NAME (default Care Managers Lookup).

Hosting & sign-in

Open at /call-manager-sync/ on your GenesysCloudToolkit ops site.

Sign in with a Genesys supervisor/admin account when prompted.
